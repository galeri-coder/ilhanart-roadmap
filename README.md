## 🌟 What is İlhanArt?

İlhanArt is a revolutionary art gallery in Ortaköy, Istanbul, pioneering the **PoArt (Proof of Art) Protocol** — a blockchain-based authentication system designed not for quarterly profits, but for **millennium-scale cultural preservation**.

This repository contains our complete roadmap, documentation, and research spanning from **2025 to 3000 CE**.

### 🎯 Core Philosophy

```
Culture > Capital
```

We reject the speculation-driven crypto culture. PoArt is not about pumping tokens or creating the next meme coin. It's about building infrastructure that outlasts us all.

## 🔑 Key Concepts

### 1. **365-Day Verification Rule**
Every artwork must remain in a cold wallet for **365 consecutive days** before authentication is recognized. This is our answer to crypto's speed addiction.

> "This is not slowness. This is civilization."

### 2. **TWAB (Time-Weighted Average Balance)**
Contribution scoring that rewards **sustained commitment** over speculation. No flash loans. No pump-and-dumps.

### 3. **Culture > Capital**
A manifesto against meme coins and speculative trading. PoArt exists to preserve culture, not extract value.

### 4. **Knowledge Beacons**
Phase 2 educators who teach the protocol to the next generation. Think of them as cultural monks for the blockchain age.

### 5. **Seal of Kethüda**
Physical NFC-enabled seals that bridge analog authenticity with digital verification.

## 🛡️ Security & Privacy

- **No Full IP Storage** — All IPs are masked (e.g., `192.168.***.***`)
- **Three Privacy Modes** — Private, Masked, Public
- **Client-Side Hashing** — Files never uploaded, only hashes
- **365-Day Cold Storage** — Hardware wallet requirement
